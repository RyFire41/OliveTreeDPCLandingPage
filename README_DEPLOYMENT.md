# Olive Tree DPC Landing Page Starter

## What this is
A low-cost, static Vite + React landing page for Olive Tree DPC.

## Before launch
1. Replace `/public/logo-horizontal.svg` with the real horizontal logo.
2. Replace `/public/logo-stacked.svg` with the final stacked logo if desired.
3. Replace `/public/favicon.svg` with the final tree-mark favicon if desired.
4. In `src/App.jsx`, replace:
   `https://tally.so/r/YOUR_FORM_ID`
   with your real interest-list form URL.

## Local setup
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Cloudflare Pages settings
- Framework preset: Vite
- Build command: npm run build
- Build output directory: dist
- Production branch: main

## Recommended form fields
- First name
- Last name
- Email
- ZIP code
- Optional: "What are you looking for in a better primary care experience?"
